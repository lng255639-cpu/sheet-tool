# 表格速算台

匯入 CSV 或 Excel，排好整理步驟，自動加總、分組、篩選，再匯出成 Excel 或 CSV。整個工具是一個 HTML 檔，用瀏覽器打開就能用，資料只在瀏覽器裡處理，不會上傳。

## 使用方式

下載 `表格速算台.html`，雙擊用瀏覽器打開。第一次開需要網路（會從 cdnjs 載入讀寫 Excel 的 [SheetJS](https://sheetjs.com/)）。

## 功能

- 匯入 `.xlsx`、`.xls`、`.csv`，可拖曳檔案，或在 Excel 複製儲存格後直接 Ctrl+V 貼上
- 中文 CSV 自動判斷 UTF-8 / Big5
- 自動找標題列（報表上方有標題、空白列也可以），全空的欄會自動略過
- 整理步驟可疊加、調整順序、暫時停用：
  - 分組彙總：加總、平均、筆數、最大、最小、不重複數
  - 篩選、排序
  - 計算欄：兩欄相加減乘除，或乘上固定數字
  - 清理：去前後空白、刪空列、去重複
  - 選取欄位、取前 N 列
- 表格底部自動統計列（合計／平均／最大／最小／筆數），點欄名可排序
- 匯出 Excel、CSV（含 BOM，Excel 開啟中文不亂碼），或複製後貼回 Excel
- 整理步驟會記在瀏覽器，下次匯入同格式的檔案自動套用

## 檔案

- `表格速算台.html`：完整的獨立網頁，直接打開使用
- `sheet-tool.html`：同一份程式，不含 `<!doctype>` 外殼，用來發佈成 Claude Artifact
